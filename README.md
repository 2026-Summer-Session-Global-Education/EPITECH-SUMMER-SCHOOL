# EPITECH SUMMER SCHOOL PROGRAM MEDIA

이 저장소는 EPITECH Summer School 과정에서 진행한 학습 자료, 웹 개발 실습, AI/자동화 프로젝트, 그리고 해커톤 결과물을 정리한 공간입니다.

## 프로젝트 소개

이 저장소에는 다음과 같은 내용이 담겨 있습니다.

- 웹 개발 실습과 React 기반 프로젝트
- AI 및 자동화 관련 학습 자료와 실습
- 해커톤 팀 프로젝트 및 발표 자료
- HTML, CSS, JavaScript, Python, React를 활용한 예제 코드

## 폴더 구성

### 1. EPITECH Hackathon
해커톤 프로젝트 관련 웹사이트, 백엔드, 발표 자료를 담고 있습니다.

- frontend: 사용자 인터페이스 구현
- backend: 서버 로직 및 API 처리
- presentation: 발표용 웹 페이지
- samples: 샘플 데이터 및 예시 파일

### 2. EPITECH SUMMER SCHOOL PROGRAM MEDIA
수업 내용별로 나누어진 학습 자료와 실습 프로젝트가 정리되어 있습니다.

- AI and Automation: AI 기반 자동화와 실습 자료
- Web Development: HTML/CSS/JavaScript부터 React까지의 웹 개발 학습 자료

## 실행 방법

### 정적 웹 페이지 열기
HTML 파일은 브라우저에서 직접 열어서 확인할 수 있습니다.

예시:
- 프로젝트 폴더 안의 index.html 파일을 브라우저로 실행

### React 프로젝트 실행
React 기반 프로젝트는 아래 순서로 실행할 수 있습니다.

```bash
npm install
npm run dev
```

### Python 백엔드 실행
Python 프로젝트는 다음과 같이 실행할 수 있습니다.

```bash
pip install -r requirements.txt
python main.py
```
